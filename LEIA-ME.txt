APURAÇÃO ELEITORAL 2026 – ÍCONE + BARRA INFERIOR

Este pacote atualiza APENAS os arquivos abaixo no projeto existente:
1. app/src/main/java/br/com/apuracaoeleitoral/MainActivity.kt
2. app/src/main/AndroidManifest.xml
3. app/src/main/res/drawable-nodpi/ic_launcher.png

No GitHub, substitua os dois arquivos de texto acima copiando o conteúdo
completo e confirmando Commit changes na branch main.
Para o arquivo PNG, abra o repositório na aba Code, entre na pasta
app/src/main/res/drawable-nodpi (crie a pasta se não existir) e use
Add file > Upload files para enviar ic_launcher.png.

Em seguida, vá a Actions > Gerar APK Android > Run workflow.
Baixe o novo APK no Artifacts da execução bem-sucedida.

A navegação inferior usa quatro áreas de mesma largura com margem à direita
para Estatísticas, ícones desenhados com Compose e área protegida contra
os botões/gestos do sistema Android.

A imagem de launcher é de autoria nova. Projeções e dados não são alterados.
O arquivo não foi compilado em Android neste ambiente: teste no GitHub Actions.
